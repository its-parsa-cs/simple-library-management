#Simple library Management System

This project was developed in November 2025, **during our first month of studying Computer Science**. It was created as a simple mid-term project.

#How it started

Neither of us had written code before. This was our very first mini-project.

The code in this repository is **kept exactly as it was originally written**. We chose not to refactor or improve it so we can look back in the future and see how much we've grown as programmers.

---

##What is this?

A simple command-line Library Management System written in Python.

*Users can manage books and members, borrow and return books, check availability, and generate simple reports.*

##How could it be improved?

*This project has many limitations, which is expected for a first-month project:*

- Inconsistent indentation and formatting
- Very little error handling
- Functions directly calling other functions
- Large global lists used as the data source
- No object-oriented programming (OOP)
- Data is stored in lists instead of files or a database

##What we learned

More importantly than the code itself, this project taught us:

- How to work together on a programming project
- How to break a problem into smaller pieces
- The fundamentals of Python programming

***Every programmer starts somewhere, and this repository is where our journey began.***
